Så ansluter du

  1. Servern är bara öppen för inbjudna. Be admin (Zunfire) lägga till ditt Minecraft-namn på listan.
  2. Starta Minecraft Java Edition 26.3. Bedrock (mobil/konsol) stöds inte.
  3. Välj Multiplayer → Add Server och skriv adressen mc.svenskserver.se
  4. Vid första inloggningen får du frågan om texturpaketet. Svara Yes för den rätta medeltidskänslan, eller No för vanliga texturer.

Texturpaket: John Smith Legacy

Smeden har valt John Smith Legacy av JimStoneCraft till världen. Det laddas ned automatiskt när du loggar in och sparas på din dator, så det tar bara tid första gången (cirka 38 MB).

Vill du installera det själv? Ladda ned det från den officiella sidan johnsmithlegacy.co.uk.

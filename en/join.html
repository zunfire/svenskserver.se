How to join

  1. Nobody gets in alone. The gate is only opened by those who already live here, and that is how every player on the server got in. Know someone who plays? Ask them to vouch for you.
  2. Start Minecraft Java Edition 26.3. Bedrock (mobile/console) is not supported.
  3. Choose Multiplayer → Add Server and enter the address mc.svenskserver.se
  4. The first time you join you will be asked about the texture pack. Answer Yes for the proper medieval feel, or No for the default textures.

Texture pack: John Smith Legacy

Smeden has chosen John Smith Legacy by JimStoneCraft for the world. It downloads automatically when you join and is saved on your computer, so it only takes time the first time (about 38 MB).

Want to install it yourself? Download it from the official site johnsmithlegacy.co.uk.
